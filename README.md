## 🛠️ Local Development Setup

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Steps to Run

1. Clone or navigate into the repository:
   ```bash
   cd Portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the Vite development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to:
   ```
   http://localhost:5173
   ```

5. Build for production:
   ```bash
   npm run build
   ```

---

## 🌐 Deployment to Vercel

1. Push your changes to GitHub:
   ```bash
   git add .
   git commit -m "Complete developer portfolio website"
   git push origin main
   ```
2. Log in to [Vercel](https://vercel.com) using your GitHub account (`Vaishnavi18p`).
3. Click **Add New Project** and select `Portfolio`.
4. Vercel automatically detects the Vite framework settings:
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
   - **Install Command:** `npm install`
5. Click **Deploy**. Your portfolio will be live with free SSL in less than a minute!
